# 사용 데이터 및 출처

(1) 소비자물가지수(CPI) 데이터

사용 목적
* 미래 생활비 상승 반영
* 실질 구매력 변화 계산
출처: 통계청 국가통계포털(KOSIS)

: 현재 생활비에 CPI 증가율을 반영하여 은퇴 시점 및 은퇴 이후의 생활비를 계산하였다. 

(2) 기준금리 데이터

사용 목적
* 자산 성장 시뮬레이션
* 복리 기반 자산 변화 계산
출처: 한국은행 경제통계시스템(ECOS) 기준금리

: 개인의 실제 투자수익률은 차이가 크므로, 객관적인 기준을 위해 기준금리를 활용하여 자산 성장률을 계산하였다. 

(3) 국민연금 데이터

사용 목적
* 예상 국민연금 수령액 계산
출처: 국민연금공단 예상연금월액표

: 사용자가 입력한 월 소득 및 가입기간과 가장 가까운 공식 데이터를 매칭하여 예상 국민연금을 계산하였다.

# SQLite 데이터베이스 구성

본 프로젝트는 SQLite를 활용하여 다음과 같은 데이터 테이블을 구성하였다.

| 테이블명             | 설명          |
| cpi              | 소비자물가지수 데이터 |
| ratefull         | 기준금리 데이터    |
| official_pension | 국민연금 데이터    |

데이터 조회는 SQL을 이용하여 수행하였다.

예시:

```sql id="m1uvmd"
SELECT year, cpi
FROM cpi
ORDER BY ABS(year - ?)
LIMIT 1;
```


# 시각화 결과(Visualization) 및 인사이트(Insights)

- CPI 실제값 및 예측값 시각화
: 대한민국 소비자물가지수(CPI)의 실제값과 예측값을 시각화하였다.

인사이트: 물가가 지속적으로 상승할 경우 동일한 생활 수준을 유지하더라도 미래에는 더 많은 생활비가 필요해진다.

즉, 단순 자산 규모보다 물가 상승 속도와 자산 성장 속도의 차이가 노후 안정성에 중요한 영향을 미친다는 점을 확인할 수 있었다. 


- 기준금리 실제값 및 예측값 시각화
: 대한민국 기준금리의 실제값과 예측값을 시각화하였다.

인사이트: 기준금리는 자산 성장의 보수적인 기준선 역할을 한다.

* 과도한 투자수익률 가정 없이
* 안정적인 장기 자산 성장 시뮬레이션

이 가능하도록 설계하였다. 


- 은퇴 이후 예상 자산 흐름
: 은퇴 이후 자산이 연령별로 어떻게 변화하는지를 시각화하였다.

인사이트: 생활비 부족분이 지속적으로 발생할 경우 자산은 점차 감소하게 된다.

특히:

* 물가 상승
* 국민연금 충당 한계가 함께 작용하면서 장기적으로 자산 소진 위험이 증가함을 확인할 수 있었다. 


- 은퇴 이후 월 생활비 부족분 변화
: 국민연금으로 충당되지 못하는 생활비 부족분을 연령별로 시각화하였다.

계산식:

```text id="m8e6l8"
생활비 부족분 = 생활비 - 국민연금
```

인사이트: 초기에는 부족분이 크지 않더라도 CPI 상승이 누적될수록 생활비 부족분이 증가하였다.

* 국민연금만으로 현재 생활 수준 유지가 어려울 수 있으며
* 추가적인 개인 저축 및 자산 관리 전략이 필요함을 보여준다.
